# Changelog

All notable changes to this project will be documented in this file.

## [v0.1.0-beta] - 2026-08-04

Initial official beta release of PopPatch.

### Added
- `coat` function: convert an assembly to the coordinates of a reference.
- `pan` function: add assembly data to an existing reference.
- Command-line options: `-f/--function`, `-h/--help`, `-u/--usage`, `-m/--map`,
  `-p/--prefix`, `-r/--reference`, `-v/--version`.
- Safe usage documentation (`PopPatch_SAFE_USAGE.md`) describing known bugs
  and limitations.

This is a beta release: the tool is functional but has known issues.
See `PopPatch_SAFE_USAGE.md` and `.github/ISSUE_TEMPLATE/known-issues.md`
for details.
